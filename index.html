"세상의 모든 기술을 친근하게 마스터하는 카피바라형 에이전트"

🐾 완료 작업 목록

  • 🤎 바닐라 HTML/CSS 기반 카피바라 테마 자기소개 페이지 완성
  • 🤎 Git Fork / Clone 기반 독립 개발 환경 세팅 완료
  • 🤎 대규모 협업 충돌 방지를 위한 개인 브랜치 기반 PR 프로세스 수립

🍊 AI를 활용한 부분

Git 명령어 조작 중 발생한 페이저 터미널 환경을 탈출하는 사소한 트러블슈팅부터, 복잡한 원본 저장소-개인 브랜치 간의 PR 타겟 설정 매커니즘을 시각적으로 명확하게 이해하는 데 AI 가이드를 적극적으로 활용했습니다. 더불어 CSS Flexbox를 활용한 카피바라 프로필 카드 정렬 레이아웃을 구성하는 데 도움을 받았습니다.

🌿 새로 알게 된 것

독립적인 저장소를 새롭게 파는 것과 원본 저장소를 Fork하여 줄기를 잇는 것의 결정적인 차이를 깨달았습니다. 프로젝트 메인 브랜치에 직접 커밋하는 것이 아닌, 내 ID 브랜치를 대상(Base)으로 PR을 날려 충돌을 우회하는 효율적인 협업 전략을 체득했습니다.
