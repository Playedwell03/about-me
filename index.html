  • 버전 관리: 독립된 work 브랜치에서 작업 단위를 명확히 나누어 커밋을 생성하고 Push하는 워크플로우 준수

  • Git 트러블슈팅 및 개념 이해: git log 페이저 탈출법부터, 독립 저장소 생성 오류를 바로잡고 Fork-Clone-Push-PR 워크플로우를 정립하는 과정에서 실시간 가이드 활용
